How to install
1) Install git and add to path
set PATH=%PATH%;C:\Program Files\Git\bin;
2) Install NodeJs
3) Go to project folder and call 'npm i'
4) Call 'npm install bower -g'
5) Call 'npm install grunt -g'
6) Call 'npm install -g grunt-cli'
7) Call 'bower i'
8) Call 'grunt' for running project or 'grunt build' for building
